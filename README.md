# Context-Aware & Mood-Based Explainable YouTube Recommendation System

## Overview
This project builds an AI-powered recommendation system that suggests YouTube videos using:

- User watch history
- Real-time mood detection
- Time-based context awareness
- Explainable AI reasoning

## Features
- Mood detection using OpenCV & DeepFace
- Context-aware recommendations
- Hybrid recommendation engine
- Filter bubble breaker
- Explainable AI output
- Interactive Streamlit dashboard

## Tech Stack
- Python
- Streamlit
- OpenCV
- DeepFace
- Scikit-learn
- Pandas
